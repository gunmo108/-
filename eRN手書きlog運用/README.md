# eRN 手書きメモ → テキスト化・蓄積 運用ガイド

手書きは今まで通り自由に書く。勤務後に写真を撮り、下の**変換プロンプト**で
テキスト化して**1シフト1ファイル**に貯める。これだけ。構造化フォームは使わない。

---

## 運用（1日3ステップ）

1. **書く**：ベッドサイドは今の紙／PowerPoint／GoodNotes 等に手書き（色・矢印・時刻そのまま）。
2. **写す**：勤務後、各患者のメモを写真に撮る。
3. **変換して貯める**：手持ちのLLM（Claude / Copilot 等）に写真＋下の「変換プロンプト」を渡し、
   出てきたテキストをその日のシフトファイルに追記する。

> ポイント：**捕捉（手書き）と整理（テキスト化）を分ける**。入口で構造化しないから摩擦が少なく、
> あとから読める・検索できる・LLMに振り返らせられる形で貯まる。

---

## ① 変換プロンプト（コピペして写真と一緒に送る）

```
あなたは遠隔ICU eRN の看護メモ書き起こしアシスタントです。
添付した手書きメモ（複数ペン色・時刻・矢印を含む）を、忠実にテキスト化してください。

【厳守】
- 書かれている内容だけを起こす。推測で補完しない。判読できない箇所は〔判読不能〕と明記。
- 患者は部屋番号／匿名IDのみ。実名・カルテ番号は書かない（写っていても伏せる）。
- ペン色の意味を残す：赤＝［重要/懸念］、青＝［申し送り］等、読み取れる範囲でタグ化。
- 時刻付きの記載は時系列のまま。矢印(→)は経過・因果として自然文にする。
- 略語・薬剤名・単位（γ, mL/h, PEEP, FiO₂, DOT 等）はそのまま保持。医学的断定を足さない。
- 書き手の判断や迷いのニュアンスも原文どおり残す。

【出力フォーマット（患者ごと）】
## 部屋番号
- 背景/診断:
- 経過（時刻順）:
  - HH:MM …
- ［重要/懸念］:
- ［申し送り］:
- Summary:
- 〔判読不能・要確認〕:
```

## ② 蓄積フォーマット（1シフト1ファイル）

ファイル名の例：`2026-07-14_日勤_KRC-SMM.md`

```
# 2026-07-14 日勤 / KRC・SMM / 担当◯名
> 変換プロンプトで起こしたテキストを患者ごとに貼る

## KRC303
- 背景/診断: …
- 経過:
  - 20:30 …
  - 24:00 …
- ［重要/懸念］: …
- ［申し送り］: …
- Summary: …

## KRC305
…
```

同じ見出し構造で貯めると、後で検索・比較・LLM分析が効く。

---

## ③（任意）あとで精度を振り返るための軽い1行タグ

「先回りできたか／現場が先だったか」を残したい介入だけ、経過の行末に1タグ付ける：

- `#先回り` / `#現場発` … どちらが先に気づいたか
- `#的中` / `#空振り` … 実際に介入が要ったか

例：`- 22:00 CVP上昇→輸液調整を先に提案 #先回り #的中`

フォーム入力ではなく手書き起こしの一部として書くだけ。集計は月末にLLMへ。

---

## ④ 月次の振り返りプロンプト（蓄積が効く本体）

その月のシフトファイルをまとめて貼り、次を送る：

```
以下は今月の遠隔ICU勤務メモ（テキスト化済み）です。私の proactive（先回り）看護の
精度を上げるために、次を日本語でまとめてください。数字は根拠の行を引用しつつ。
1. #先回り と #現場発 の件数と割合。#的中/#空振り の内訳。
2. 「先回りが当たった」場面に共通する特徴（時間帯・鎮静・拠点・疾患・所見）。
3. 「現場に先を越された／空振りした」場面の共通点。
4. 来月、どの状況を優先して先回り監視すべきかの具体的な提案を3つ。
5. 記録の付け方で改善すると分析しやすくなる点。
```

## よくある疑問

- **Q. 匿名化は？** 部屋番号・匿名IDのみで運用。プロンプトも実名を伏せるよう指示済み。写真も個人が
  特定できる情報が写り込まないように。
- **Q. オフラインでも？** テキスト化はLLM（通信要）。手書き自体はオフライン。夜間は書きためて後でまとめて変換でOK。
- **Q. 前に作ったアプリは？** 入力ツールとしては使わない。将来この蓄積テキストから精度分析だけ
  やりたくなったら、アプリの「蓄積分析」部分に取り込む使い方に切り替えられる（必要時に相談）。
