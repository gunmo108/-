# STEEL CHAIN ─鋼鉄連鎖─

**ロボット = デッキ** のローグライクデッキビルドゲーム。
頭部 / 右腕 / 左腕 / 脚部にパーツ(カード)をセットし、同属性カードを連鎖させてダメージを **×2 → ×4 → ×8 → ×16(最大×32)** に膨らませろ。

![ジャンル](https://img.shields.io/badge/genre-roguelike%20deckbuilder-orange)
依存ライブラリゼロ / ビルド不要 / ブラウザだけで動作。

## 遊び方(起動)

```bash
# そのまま index.html をブラウザで開くだけ
open index.html        # mac
start index.html       # windows

# またはローカルサーバで
python3 -m http.server 8000
# → http://localhost:8000
```

## ゲームシステム

### ロボット = デッキ(メダロット式)
- 機体は **頭部 / 右腕 / 左腕 / 脚部** の4パーツ構成。
- 装備した各パーツが持つカードが、そのまま戦闘デッキになる。
- パーツを集めて換装することが「デッキ構築」。パーツのHPは戦闘をまたいで持続する。

### 部位破壊
- パーツ単位でHPがあり、破壊されたパーツのカードは**その戦闘中デッキから消滅**する。
- **自機の頭部破壊 = 敗北 / 敵の頭部(コア)破壊 = 勝利**。
- 腕を折って敵を無力化してから料理するか、頭部に全弾叩き込んで速攻するかはプレイヤーの選択。部位破壊にはクレジットボーナスもある。

### コンボシステム(脳汁担当)
- カード属性は <b>射撃 / 格闘 / 支援</b> の3種+無属性。
- **同属性を連続で出すたびに、ダメージ・ブロック・修理量が倍々**になる。
  `1枚目 ×1 → 2枚目 ×2 → ×4 → ×8 → ×16`(バーサクヘッド装備で ×32)
- コンボはターンをまたいで持続。ただし敵の**ジャミング**で消される。
- 無属性カード(ドロー/エナジー系)はコンボを崩さない潤滑油。
- 「チャージ」でコンボLvを直接加速、「ジャッジメント」でコンボを爆発させる、などのビルドが組める。
- 手札には現在のコンボを乗せた**実ダメージがプレビュー表示**される。

### ラン構造(全12フロア)
- 各フロアで進行ルートを選択: **戦闘 ⚔ / 強敵 ☠ / ショップ ◈ / 整備班 ✚ / ??? ? / ボス 👑**
- 戦闘報酬でパーツを入手し、倉庫と換装しながらボス **Ω-FRAME** を目指す。
- 修理を怠ると、ボス前に腕が消し飛ぶ。リソース管理もデッキビルドの一部。

### 操作
| 操作 | 内容 |
|---|---|
| カードクリック / 数字キー1〜8 | カード使用 |
| E | ターン終了 |
| 敵パーツをクリック | 攻撃対象の変更 |

## 技術構成

- Vanilla JS / HTML / CSS のみ。外部依存・ビルド工程なし(`file://` で直接動作)。
- 効果音は WebAudio によるリアルタイム合成(音声アセット不要)。
- 演出: 画面シェイク・ダメージポップ・コンボバナー・パーティクルは CSS アニメーション。

```
index.html      画面骨格
style.css       スタイル/演出
js/data.js      カード・パーツ・敵・マップ・イベント定義
js/sfx.js       WebAudio合成効果音
js/fx.js        画面演出(ポップ/シェイク/バナー/粒子)
js/battle.js    戦闘システム(コンボ/部位破壊/敵AI)
js/run.js       ラン進行(マップ/報酬/ショップ/休憩/イベント/編成)
js/main.js      起動・画面遷移・キー入力
test/smoke.js   ヘッドレス検証(node test/smoke.js)
```

## テスト

```bash
node test/smoke.js
```
DOMスタブ上で データ整合性 / フルラン進行 / コンボ倍率計算 / 全イベント分岐 / ボス戦 を自動シミュレートする。
